Local dev image now requires a GitHub App installation token to clone the private `layer8-core-api-py-client` dependency. `tasks.py::build` mints the token in a one-shot Python container and writes it as a BuildKit secret consumed by `development/Dockerfile`. Set `LAYER8_GITHUB_APP_ID`, `LAYER8_GITHUB_INSTALLATION_ID`, and `LAYER8_GITHUB_APP_PRIVATE_KEY` (path to PEM) in your shell before `invoke build`.
